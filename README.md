# 📚 Home Library — Python

A simple console-based library management application written in Python.

**Home Library** allows users to manage a personal book collection directly from the terminal.

## Features

- Add new books with title and author
- Display all books in the library
- Delete books by their number
- Edit book titles and authors
- Search for books by title
- View library statistics:
  - Total number of books
  - Number of unique authors
- Handle invalid numeric input
- Exit the application

## Technologies

- Python 3
- Lists
- Dictionaries
- Sets
- Loops (`for`, `while`)
- Conditional statements (`if`, `elif`, `else`)
- Exception handling (`try`, `except`)

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/byraqq/home-library-python.git
   ```
3. Open the project folder.
4. Run:
   ```bash
   python kai.py
   ```

# 📚 Домашняя библиотека — Python

Простое консольное приложение для управления личной библиотекой, написанное на Python.

**Домашняя библиотека** позволяет управлять коллекцией книг прямо через терминал.

## Возможности

- Добавление книг с названием и автором
- Просмотр всех книг
- Удаление книг по номеру
- Редактирование названия и автора
- Поиск книг по названию
- Просмотр статистики библиотеки:
  - Общее количество книг
  - Количество уникальных авторов
- Обработка неправильного числового ввода
- Выход из программы

## Используемые технологии

- Python 3
- Списки
- Словари
- Множества
- Циклы (`for`, `while`)
- Условные конструкции (`if`, `elif`, `else`)
- Обработка исключений (`try`, `except`)

## Как запустить

1. Установите Python 3.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/byraqq/home-library-python.git
   ```
3. Откройте папку проекта.
4. Запустите программу:
